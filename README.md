# Shallow

Launcher de jeux local pour Windows, construit avec Electron.

- Scanne tes dossiers de jeux et détecte l'exécutable de chaque jeu
- Récupère automatiquement jaquettes, bannières et infos via Steam
- Favoris, jeux masqués, ajout manuel
- Suivi du temps de jeu

## Lancer en développement

```bash
npm install
npm start
```

## Créer l'installateur

```bash
npm run dist
```

L'installateur est généré dans `dist/`.
